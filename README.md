# TOJAR DZ — لوحة التحكم

Arabic RTL e-commerce admin dashboard built with React + Vite + Tailwind CSS.

## Setup

```bash
npm install
npm run build
```

## Development

```bash
npm run dev
```

## Deployment — Cloudflare Pages

| Setting | Value |
|---|---|
| Build command | `npm run build` |
| Build output directory | `dist` |
| Node version | 18 or 20 |

The `public/_redirects` file handles SPA routing automatically on Cloudflare Pages.

## Stack

- React 19 + TypeScript
- Vite 6
- Tailwind CSS v4
- Recharts (charts)
- Lucide React (icons)
- Cairo font (Google Fonts)
